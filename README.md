# IT-Support-Home-Lab

## About This Portfolio

This repository documents my hands-on learning and practice in IT support, troubleshooting, and systems administration.

The goal is to develop practical technical skills through a virtual home lab, document real troubleshooting experiences, and build familiarity with tools and environments commonly used in IT support roles.

## Lab Environment

**Hardware**
- HP laptop
- 16 GB RAM
- VirtualBox virtualization software

**Virtual Machines**
- Windows 11
- Windows Server 2025

**Networking**
- VirtualBox NAT Network
- DHCP and IP addressing
- Network connectivity testing
- Windows Defender Firewall configuration
