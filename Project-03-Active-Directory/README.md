# Project 03 — Active Directory

## Overview
This project demonstrates hands-on practice with Windows Server 2025 and Active Directory in a virtual home lab environment.

The goal is to simulate common IT helpdesk tasks involving domain users, organizational units, security groups, and account management.

## Lab Environment
- **Server OS:** Windows Server 2025
- **Client OS:** Windows 11
- **Virtualization:** Oracle VirtualBox
- **Domain:** adlab.test
- **Server Name:** HELPDESK-SRV01

## Exercises
- **HD-001 — Password Reset:** Completed
- **HD-002 — Account Lockout:** Planned

## Skills Practiced
- Active Directory Domain Services (AD DS)
- Creating and managing domain user accounts
- Organizational units (OUs)
- Security groups and group membership
- Password resets and account management
- Helpdesk troubleshooting and documentation
